# SLM 项目 · 后端 A

这是分工文档中的数值计算模块。使用基础 C++、`vector`、`complex` 和普通循环实现，不依赖第三方数学库。源代码只在板块开头添加简短注释。

当前目录就是新建的 `cpp大作业` 文件夹，所有源码、测试和运行说明都放在这里。

## 1. 已完成的内容

| 文件 | 作用 |
| --- | --- |
| `core/Fft.h`、`core/Fft.cpp` | 一维、二维 FFT 和逆 FFT |
| `core/Asm.h`、`core/Asm.cpp` | ASM 正向、反向传播及光强计算 |
| `core/Metrics.h`、`core/Metrics.cpp` | MSE、PSNR |
| `core/Axial.h`、`core/Axial.cpp` | 轴向剖面、进度回调、取消计算 |
| `core/SlmTypes.h` | 分工文档给出的公共结构和接口 |
| `tests/CoreSmokeTests.cpp` | 独立数值测试 |
| `examples/BackendADemo.cpp` | 高斯光束通过透镜后的传播示例 |
| `build_and_test.bat` | 自动寻找 Visual Studio、编译、测试并运行示例 |

按评分标准，这部分完成了后端 A 的基本功能，并提供轴向采样、进度、取消和参数检查。整个项目还需要其他同学完成 MFC 界面、图像导入导出、GS 和快速搜索，最终成绩由整组集成效果决定。

## 2. 怎样编译和运行

在本文件夹打开终端，执行：

```powershell
.\build_and_test.bat
```

需要安装 Visual Studio 的“使用 C++ 的桌面开发”组件。脚本会自动寻找编译器，不需要手动修改环境变量。核心代码使用 C++11 语法；MSVC 的最低显式标准选项是 C++14，因此脚本使用 `/std:c++14`。

成功后，终端会显示测试通过数量和 `Build and tests completed successfully.`。所有生成文件都在 `build` 文件夹：

- `CoreSmokeTests.exe`：可单独再次运行测试。
- `BackendADemo.exe`：可单独再次运行传播示例。
- `input_intensity.csv`：输入光束的归一化光强，256×256。
- `reconstruction.csv`：传播到 0.10 m 后的归一化光强，256×256。
- `axial.csv`：从 0 到 0.20 m 的 31 个切片，宽 256、高 31。

CSV 不包含表头，行列与图像数组一致。示例单独运行时，CSV 会写到终端当前目录。示例打印的 MSE 和 PSNR 用于验证零距离传播恒等关系，不是 GS 重建质量成绩；MSE 为 0 时 PSNR 显示 `inf` 是正常结果。

也可以用 Visual Studio 打开本文件夹，选择 CMake 工程进行构建。或者在已配置 CMake 和编译器的终端执行：

```text
cmake -S . -B build/cmake
cmake --build build/cmake --config Release
ctest --test-dir build/cmake -C Release --output-on-failure
```

## 3. 与其他同学的代码连接

把 `Fft.cpp`、`Asm.cpp`、`Metrics.cpp`、`Axial.cpp` 和对应头文件加入总工程。如果组长已经建立了 `SlmTypes.h`，使用组长版本核对字段，不要产生两份相同结构定义。本项目内的版本按分工文档提供。

MFC 工程通常默认要求预编译头。选中这四个 `.cpp`，在“属性 → C/C++ → 预编译头”中选择“不使用预编译头”；在“C/C++ → 命令行”中加入 `/utf-8`，以正确处理中文进度文字。不需要往数值代码中加入 MFC 头文件。

`RunSimulation` 仅保留文档中的声明，由后端 B 实现。不要把控制台示例和测试的 `main` 加入 MFC 工程。

后端 B 可以这样使用现有接口：

```cpp
#include "Asm.h"
#include "Metrics.h"
#include "Axial.h"

// 将优化得到的相位转换为单位振幅复数场，再计算传播结果。
std::vector<std::complex<double>> field(phase.size());
for (std::size_t i = 0; i < phase.size(); ++i) {
    field[i] = std::polar(1.0, phase[i]);
}

std::vector<std::complex<double>> propagated = PropagateAsm(
    field, config.size, config.pixelPitch_m,
    config.wavelength_m, config.distance_m);

result.reconstruction = IntensityOf(propagated, config.size);
result.mse = ComputeMse(target, result.reconstruction);
result.psnr = ComputePsnr(result.mse);

result.axial = ComputeAxialSection(
    field, config.size, config.pixelPitch_m, config.wavelength_m,
    0.0, config.distance_m, config.axialSlices,
    cancelRequested, onProgress);
```

这段是 `RunSimulation` 内部的调用片段：`phase` 为后端 B 算出的相位数组，`target` 为准备好的目标光强，其他变量来自公共接口。正距离场景使用上述区间；若目标距离为负，轴向起止值应改为 `config.distance_m, 0.0`。

GS 反向传播时，将 `distance_m` 改成负数。后端 B 用传播场的相位和 `sqrt(target.data[i])` 组成新的复数场，再做反向传播；不要把显示用的归一化光强代替复振幅场参与传播。

轴向回调的百分比只表示轴向阶段的进度，`iteration` 保持 0。组长需要把它映射到整体进度，例如 GS 使用 0～80%，轴向使用 80～100%。回调在调用该函数的线程执行，不能直接更新 MFC 控件。

无效参数抛出 `std::invalid_argument`，数值溢出抛出 `std::overflow_error`，取消抛出 `std::runtime_error`。工作线程应捕获 `std::exception`：若取消标志为真则提示“已取消”，否则显示异常消息。取消在每个传播切片前后检查，单次 FFT/ASM 内部没有取消检查。

## 4. 数据和公式约定

- 二维数组按行保存：`data[y * size + x]`。二维场必须为正方形，边长为正的 2 的幂，常用 64、128、256、512。
- 波长、像素间距和传播距离一律用米。532 nm 写成 `532e-9`，8 μm 写成 `8e-6`，300 mm 写成 `0.30`。
- FFT 正变换的指数为负；逆变换指数为正，并除以一维长度。二维逆变换总共除以 `size * size`。频谱使用 FFT 原始排列，不执行 `fftshift`。
- ASM 采用 `IFFT2(FFT2(U) × H)`，其中 `H = exp(i × 2πz/λ × sqrt(1 - (λfx)² - (λfy)²))`。零频在数组开头，后半段索引对应负频率。
- 根号内小于 0 的频率属于倏逝分量，非零距离传播时直接滤除，避免反向传播出现指数放大。零距离严格返回原场。存在被滤除分量时，正反传播不保证恢复原场。
- `IntensityOf` 先计算 `real² + imag²`，再除以该图最大值，输出范围为 0～1；全黑场保持为零。它保留相对光强形状，不保留绝对能量。检查能量应对原始复数场累加 `std::norm`。
- MSE 是逐像素平方误差的平均值，输入必须同尺寸且为有限的 0～1 光强。本模块不会偷偷调整目标图亮度。后端 B 应与图像模块统一目标图归一化方式。
- PSNR 为 `-10 × log10(MSE)`，采用归一化峰值 1，MSE 为 0 时返回正无穷。
- 轴向图取每个传播面的 `y = size / 2` 行。每个距离都从原始场出发；有多个切片时含起点和终点，只有一个切片时取起点。整张剖面统一按最大光强归一化。

这是适合课程项目的基础离散 ASM。FFT 计算具有周期边界，没有额外做补零或带限抗混叠；图案靠近边缘、距离过大或采样不足时会有回绕或混叠，应结合图像范围和采样参数观察结果。

FFT 符号约定可对照 [FFTW 官方说明](https://www.fftw.org/fftw3_doc/What-FFTW-Really-Computes.html)。本实现自行编写，不使用 FFTW 库；逆变换归一化方式以上述本项目约定为准。

## 5. 答辩时可以这样解释

“我负责把复振幅场传播到指定距离。先用二维 FFT 把场拆成不同空间频率，为每个频率乘上距离对应的相位因子，再逆 FFT 得到传播场。光强由复数模平方计算，MSE 和 PSNR 用于评价目标图和重建图的差异。重复传播并取中心一行，就能得到沿传播方向的轴向剖面。”

FFT 部分使用二进制倒序和蝶形运算，二维处理是先逐行、再逐列。测试不仅检查程序是否运行，还与直接 DFT 和平面波解析解比较，并检查非法参数和取消操作。
